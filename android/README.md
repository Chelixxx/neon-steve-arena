# VOLTRA Android APK

Android-оболочка для текущего веб-клиента VOLTRA. Сервер, аккаунты, чаты и баланс ϟ остаются общими с веб-версией.

## Сборка
1. Открой папку `android` в Android Studio.
2. Используй JDK 17 и Android SDK Platform 35.
3. Дождись Gradle Sync.
4. Выбери **Build → Build APK(s)**.
5. Debug APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

В репозитории есть GitHub Actions workflow `.github/workflows/android-apk.yml`, который запускает сборку при изменениях в `android/**`. При успешной сборке он публикует предварительный APK в релизе `android-preview`.

## Возможности
- WebView-клиент для production-сайта VOLTRA.
- Загрузка файлов через системный выбор файлов.
- При сетевой ошибке открывается локальная страница `offline.html`.
- Локальный текстовый чат между двумя предварительно сопряжёнными Android-устройствами по Bluetooth Classic.
- Переключение между встроенными иконками приложения: фиолетовая, бирюзовая и розовая.

## Bluetooth-чат
1. На обоих телефонах открой системные настройки Bluetooth и выполни сопряжение.
2. На первом телефоне в локальном режиме нажми «Ожидать подключение».
3. На втором выбери первый телефон в списке и нажми «Подключиться».
4. Сообщения передаются напрямую по Bluetooth; интернет для передачи не нужен.

Это отдельный локальный чат: он не синхронизируется автоматически с серверными чатами. Без сети нельзя войти в аккаунт или получить серверную историю, если она не была загружена заранее.

## Перед публичным релизом
Проверь сборку на нескольких реальных Android-устройствах, все разрешения и поведение при отключении сети. Debug APK предназначен для тестирования; публичную версию нужно подписать релизным ключом и проверить перед распространением.
