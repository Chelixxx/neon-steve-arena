# NEON STEVE ARENA — мультиплеерная браузерная игра

Авторский стартовый прототип .io-арены, вдохновлённый жанром игр со сбором кристаллов. Не копирует оригинальные ассеты.

## Возможности
- Настоящие игроки на одном Node.js WebSocket сервере, одна общая арена
- Серверная симуляция движения, сбора кристаллов и очков; сервер не доверяет клиентским координатам/очкам
- Неоновый Canvas 2D, персонажи растут по мере набора очков, лидерборд
- Клавиатура WASD/стрелки и сенсорный джойстик
- Один HTTP+WebSocket сервер на одном порту, health endpoint `/health`

## Запуск на ПК (Windows)
1. Установите Node.js 18 или новее с npm.
2. Распакуйте ZIP в папку, например `C:\neon_steve_arena`.
3. Откройте терминал в этой папке.
4. Выполните `npm install`, затем `npm start`.
5. Откройте `http://localhost:8000`.
6. Для проверки мультиплеера откройте игру в двух вкладках/браузерах и войдите с разными никами.
7. Телефон в той же Wi-Fi сети: `http://IP_КОМПЬЮТЕРА:8000` (узнайте IPv4 командой `ipconfig`). Разрешите входящие подключения в брандмауэре, если потребуется.

## Публикация онлайн
Tilda не запускает Node.js. Нужен отдельный хостинг, поддерживающий постоянно работающий Node.js процесс и WebSocket (например VPS или сервис приложений с поддержкой WebSocket).
1. Загрузите содержимое папки на сервер.
2. Установите зависимости `npm install --omit=dev`.
3. Запустите `npm start`, настройте постоянный запуск процесса.
4. Привяжите HTTPS-домен, например `arena.yourdomain.example`, через reverse proxy с WebSocket Upgrade (wss://).
5. Убедитесь, что `https://ВАШ-АДРЕС/health` возвращает `{"ok":true,...}`.
6. В Tilda создайте страницу, укажите URL `/game` в настройках страницы, добавьте блок «Другое → T123».
7. Вставьте код из `TILDA_T123.html`, заменив `https://YOUR-GAME-SERVER.example/` на реальный HTTPS-адрес игры. Опубликуйте страницу.
8. Проверьте `https://veka-line.shop/game` с телефона и ПК.

**Важно:** HTTPS-страница Tilda должна загружать HTTPS iframe, а WebSocket автоматически подключится через WSS. Локальный HTTP сервер нельзя встраивать в публичную HTTPS страницу.

## Ограничения прототипа
- Нет аккаунтов, чата, постоянного хранения очков, антибот-защиты, комнат и матчмейкинга.
- Игровой прогресс сбрасывается при отключении или перезапуске сервера.
- Один процесс сервера; для масштабирования потребуется общая система состояния.
- Для публичного запуска рекомендуются HTTPS, rate limiting, мониторинг и ограничения по соединениям.
- Не проводилось полноценное нагрузочное и кроссбраузерное тестирование.

## Структура
- `server.js` — HTTP, WebSocket, серверная симуляция.
- `public/index.html` — интерфейс.
- `public/style.css` — неоновый дизайн.
- `public/game.js` — Canvas-отрисовка, управление, сетевой клиент.
- `TILDA_T123.html` — встраивание в Tilda.
